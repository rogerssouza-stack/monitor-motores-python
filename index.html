Explicação Técnica & Arquitetura

Como o algoritmo processa, valida e classifica a saúde operacional de cada ativo.

01

Ingestão e Validação de Integridade

A função validar_leitura() atua como filtro de sanitização, verificando a presença de todos os campos obrigatórios (ID, setor, temperatura, corrente, vibração, RPM e potência) e descartando leituras corrompidas ou com valores físicos negativos antes do processamento.

02

Motor de Regras e Limites Operacionais

Cada leitura válida é comparada contra o dicionário LIMITES em analisar_alertas(). O sistema avalia simultaneamente sobrecarga térmica, sobrecorrente de fase, severidade de vibração mecânica e desvio de rotação síncrona.

03

Classificação de Severidade

A criticidade é definida pela contagem de violações simultâneas: NORMAL (0 alertas), ATENÇÃO (1 parâmetro fora da faixa) e CRÍTICO (2 ou mais falhas combinadas, indicando risco iminente de quebra).

04

Consolidação e Plano de Ação

As funções calcular_estatisticas() e gerar_plano_manutencao() agregam indicadores globais da planta (potência instalada ativa, médias térmicas/elétricas) e direcionam as equipes para parada imediata ou inspeção programada.

Parâmetros Monitorados e Limites de Segurança

Thresholds configurados no sistema para disparo automático de alertas.

Parâmetro Variável no Código Faixa Segura Limite de Disparo Risco Associado
Temperatura temperatura_max 0.0 °C – 80.0 °C > 80.0 °C Degradação do verniz isolante dos enrolamentos e falha térmica.
Corrente Elétrica corrente_max 0.0 A – 18.5 A > 18.5 A Sobrecarga mecânica no eixo, queda de tensão ou desbalanceamento de fases.
Vibração Mecânica vibracao_max 0.0 mm/s – 4.5 mm/s > 4.5 mm/s Desalinhamento de acoplamento, folga estrutural ou desgaste de rolamentos.
Rotação (RPM) rpm_min / rpm_max 1400 – 1800 RPM < 1400 ou > 1800 RPM Escorregamento excessivo do rotor ou falha no inversor de frequência.
Potência Nominal potencia_kw Informativo (kW) Agregação global Cálculo de carga instalada total e demanda energética por setor.

from datetime import datetime

# ==============================================================================
# CONFIGURAÇÕES E CONSTANTES DO SISTEMA
# ==============================================================================
SISTEMA_NOME = "Monitoramento de Motores Industriais"
VERSAO = "1.0.0"

LIMITES = {
    "temperatura_max": 80.0,
    "corrente_max": 18.5,
    "vibracao_max": 4.5,
    "rpm_min": 1400,
    "rpm_max": 1800,
}

LEITURAS_MOTORES = [
    {"id": "MTR-01", "setor": "Estamparia", "temperatura": 68.4, "corrente": 14.2, "vibracao": 2.1, "rpm": 1750, "potencia_kw": 7.5},
    {"id": "MTR-02", "setor": "Usinagem",   "temperatura": 84.7, "corrente": 19.3, "vibracao": 5.2, "rpm": 1690, "potencia_kw": 11.0},
    {"id": "MTR-03", "setor": "Bobinagem",  "temperatura": 76.2, "corrente": 17.8, "vibracao": 4.7, "rpm": 1520, "potencia_kw": 5.5},
    {"id": "MTR-04", "setor": "Pintura",    "temperatura": 61.0, "corrente": 11.5, "vibracao": 1.8, "rpm": 1780, "potencia_kw": 7.5},
]


# ==============================================================================
# VALIDAÇÃO DE DADOS
# ==============================================================================
def validar_leitura(motor: dict) -> bool:
    """Verifica se todos os campos obrigatórios existem e possuem valores válidos."""
    campos_obrigatorios = ["id", "setor", "temperatura", "corrente", "vibracao", "rpm", "potencia_kw"]
    for campo in campos_obrigatorios:
        if campo not in motor or motor[campo] is None:
            return False

    if (
        motor["temperatura"] < 0
        or motor["corrente"] < 0
        or motor["vibracao"] < 0
        or motor["rpm"] < 0
    ):
        return False

    return True


def obter_leituras_validas(lista_motores: list) -> list:
    """Filtra e retorna apenas os registros aprovados na validação."""
    return [m for m in lista_motores if validar_leitura(m)]


# ==============================================================================
# DIAGNÓSTICO E ANÁLISE DE ALERTAS
# ==============================================================================
def analisar_alertas(motor: dict) -> tuple[str, list]:
    """Compara as métricas do motor com os limites e classifica o status."""
    alertas = []

    if motor["temperatura"] > LIMITES["temperatura_max"]:
        alertas.append(f"Superaquecimento ({motor['temperatura']:.1f} C)")
    if motor["corrente"] > LIMITES["corrente_max"]:
        alertas.append(f"Sobrecorrente ({motor['corrente']:.1f} A)")
    if motor["vibracao"] > LIMITES["vibracao_max"]:
        alertas.append(f"Vibracao elevada ({motor['vibracao']:.1f} mm/s)")
    if motor["rpm"] < LIMITES["rpm_min"] or motor["rpm"] > LIMITES["rpm_max"]:
        alertas.append(f"Rotacao fora da faixa ({motor['rpm']} RPM)")

    if len(alertas) == 0:
        status = "NORMAL"
    elif len(alertas) == 1:
        status = "ATENCAO"
    else:
        status = "CRITICO"

    return status, alertas


def calcular_estatisticas(motores: list) -> dict:
    """Calcula médias operacionais, potência total e identifica o motor mais quente."""
    total = len(motores)
    if total == 0:
        return {}

    temp_media = sum(m["temperatura"] for m in motores) / total
    corrente_media = sum(m["corrente"] for m in motores) / total
    potencia_total = sum(m["potencia_kw"] for m in motores)
    maior_temp = max(motores, key=lambda m: m["temperatura"])

    return {
        "total_motores": total,
        "temperatura_media": round(temp_media, 2),
        "corrente_media": round(corrente_media, 2),
        "potencia_total_kw": round(potencia_total, 2),
        "motor_mais_quente": maior_temp["id"],
    }


def gerar_plano_manutencao(motores: list) -> dict:
    """Agrupa os motores por nível de criticidade para ação da equipe técnica."""
    plano = {"CRITICO": [], "ATENCAO": [], "NORMAL": []}
    for motor in motores:
        status, alertas = analisar_alertas(motor)
        plano[status].append({
            "id": motor["id"],
            "setor": motor["setor"],
            "ocorrencias": len(alertas),
        })
    return plano


# ==============================================================================
# EXIBIÇÃO NO TERMINAL
# ==============================================================================
def exibir_painel(motores: list) -> None:
    print("=" * 64)
    print(f"{SISTEMA_NOME} - v{VERSAO}")
    print(f"Data/Hora da leitura: {datetime.now().strftime('%d/%m/%Y %H:%M:%S')}")
    print("=" * 64)

    for motor in motores:
        status, alertas = analisar_alertas(motor)
        print(
            f"[{status:<7}] {motor['id']} ({motor['setor']}) | "
            f"Temp: {motor['temperatura']} C | Corr: {motor['corrente']} A | "
            f"Vib: {motor['vibracao']} mm/s | RPM: {motor['rpm']}"
        )
        for alerta in alertas:
            print(f"  -> Alerta: {alerta}")

    stats = calcular_estatisticas(motores)
    print("-" * 64)
    print(
        f"Resumo: {stats['total_motores']} motores | "
        f"Temp. media: {stats['temperatura_media']} C | "
        f"Corr. media: {stats['corrente_media']} A | "
        f"Potencia total: {stats['potencia_total_kw']} kW | "
        f"Maior temp.: {stats['motor_mais_quente']}"
    )
    print("=" * 64)


def exibir_manutencao(motores: list) -> None:
    plano = gerar_plano_manutencao(motores)
    print("\nPLANO DE MANUTENCAO PREVENTIVA:")
    print(f" - Parada imediata (CRITICO): {[m['id'] for m in plano['CRITICO']]}")
    print(f" - Inspecao programada (ATENCAO): {[m['id'] for m in plano['ATENCAO']]}")
    print(f" - Operacao estavel (NORMAL): {[m['id'] for m in plano['NORMAL']]}")


# ==============================================================================
# PONTO DE ENTRADA PRINCIPAL
# ==============================================================================
if __name__ == "__main__":
    motores_validos = obter_leituras_validas(LEITURAS_MOTORES)
    exibir_painel(motores_validos)
    exibir_manutencao(motores_validos)
